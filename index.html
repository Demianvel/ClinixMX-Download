Preguntas frecuentes

¿Dónde se descarga Clinix MX?

Desde esta web, mediante el botón de descarga oficial. El archivo se obtiene desde GitHub Releases.

¿El repositorio del código fuente es público?

No. El código fuente, billing y lógica privada permanecen en un repositorio privado y no forman parte de este sitio.

¿Qué ocurre cuando sale una actualización?

La distribución usa el endpoint de última versión de GitHub Releases, por lo que el botón continúa apuntando automáticamente a la versión más reciente.

¿La web procesa tarjetas?

No. La web pública no solicita ni almacena datos de tarjetas. El pago real debe realizarse mediante un checkout seguro conectado al backend de Clinix MX.
